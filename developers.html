How LibreHU works, down to the bytes. Everything here comes from the repositories' code and docs, the analysis of the stock firmware and measurements on the Jancar UJC201; each section links to its source.Comment marche LibreHU, jusqu'à l'octet. ArchitectureArchitecture

One privileged service owns the hardware; every other app goes through it. Nothing else opens the MCU serial port.Un seul service privilégié tient le matériel ; toutes les autres applis passent par lui. Rien d'autre n'ouvre le port série de la MCU.

  • core/ of LibreHU-service is plain Kotlin/JVM (MCU framing and profiles, Hiworld decoding, OBD formulas, touch maths, bridge crypto) with unit tests runnable without the Android SDK: ./gradlew -PcoreOnly :core:test.core/ de LibreHU-service est du Kotlin/JVM pur (trames et profils MCU, décodage Hiworld, formules OBD, calculs tactiles, crypto du pont) avec des tests unitaires lançables sans SDK Android : ./gradlew -PcoreOnly :core:test.
  • All apps: Kotlin, Jetpack Compose, minSdk 28 (Android 9), target 35, R8 without obfuscation, one shared public signing key.Toutes les applis : Kotlin, Jetpack Compose, minSdk 28 (Android 9), cible 35, R8 sans renommage, une clé de signature publique commune.

GPIO, I²C, inputs

/dev/gpios_ioctl (Jancar module, reimplemented in the LibreHU kernel): ioctl(fd, cmd, &gpio), the argument points to the GPIO number. 0x6B00 high, 0x6B01 low, 0x6B02 input, 0x6B03 read (level returned). Reading switches the pin to input: never read an output./dev/gpios_ioctl (module Jancar, réimplémenté dans le noyau LibreHU) : ioctl(fd, cmd, &gpio), l'argument pointe vers le numéro de GPIO. 0x6B00 haut, 0x6B01 bas, 0x6B02 entrée, 0x6B03 lecture (niveau renvoyé). Lire passe la broche en entrée : ne jamais lire une sortie.

Partitions, AVBPartitions, AVB

  • recovery is exactly 32 MiB; the bootloader message (BCB) lives on para (no /misc); boot is system-as-root.recovery fait exactement 32 Mio ; le message du bootloader (BCB) est sur para (pas de /misc) ; boot est en system-as-root.
  • The stock vbmeta chains recovery (Jancar key, public key digest 0aa0987116fc792f36bc909b0a4d530413f02a54, rollback location 1): a custom recovery must carry the stock recovery's vbmeta footer, else Android bootloops. TWRP's post-processing does that.Le vbmeta d'origine chaîne recovery (clé Jancar, empreinte de clé publique 0aa0987116fc792f36bc909b0a4d530413f02a54, rollback location 1) : un recovery modifié doit porter le pied vbmeta du recovery d'origine, sinon Android boucle. Le post-traitement de TWRP le fait.
  • fastboot boot does not work on this unit: flash recovery. Init does not rewrite recovery at boot (flash_recovery commented out in /system/init.rc).fastboot boot ne marche pas sur cet autoradio : flasher recovery. Init ne réécrit pas le recovery au démarrage (flash_recovery commenté dans /system/init.rc).
  • Metazone (/dev/mtz, Autochips): rotation, camera format, panel parameters. LibreHU reads it and writes only the camera format, like Jancar.Metazone (/dev/mtz, Autochips) : rotation, format caméra, paramètres de dalle. LibreHU la lit et n'écrit que le format caméra, comme Jancar.

MCU protocol (JAC_V1)Protocole MCU (JAC_V1)

Reverse engineered from the firmware (jacmcu.bin) and the stock Android stack; full analysis in MCU-tools-app/docs/mcu_firmware.md.Retrouvé à partir du firmware (jacmcu.bin) et de la pile Android d'origine ; analyse complète dans MCU-tools-app/docs/mcu_firmware.md.

FrameTrame

EE FA LEN CMD D0 .. Dn-1 CS     LEN = n + 1     CS = (EE + FA + LEN + CMD + D0 + .. + Dn-1) & 0xFF
examplesexemples: EE FA 02 1F 01 0A   (PC_READY)     EE FA 03 F0 00 00 DB   (ACC?ACC ?)
  • /dev/ttyS1 ↔ MCU USART2, 115200 8N1. Data ≤ 130 bytes; the MCU drops a frame after 1 s without a byte./dev/ttyS1 ↔ USART2 de la MCU, 115200 8N1. Données ≤ 130 octets ; la MCU abandonne une trame après 1 s sans octet.
  • Every valid frame except C0 is acknowledged with C0 <cmd> <d0> <d1>. LibreHU resends 1F 08 01 F1 80 every 500 ms, 5 times, until acknowledged.Toute trame valide sauf C0 est acquittée par C0 <cmd> <d0> <d1>. LibreHU renvoie 1F 08 01 F1 80 toutes les 500 ms, 5 fois, jusqu'à l'acquittement.
  • Long frames (CAN data, LEN ≥ 0x80) must be read with an unsigned length: the stock Android stack crashes on them.Les trames longues (données CAN, LEN ≥ 0x80) doivent être lues avec une longueur non signée : la pile Android d'origine plante dessus.
  • At start, send 1F 01 (PC_READY): the MCU answers ACC (00), version (0A, +200 ms), date and time (09, +400 ms). No heartbeat to keep.Au démarrage, envoyer 1F 01 (PC_READY) : la MCU répond ACC (00), version (0A, +200 ms), date et heure (09, +400 ms). Aucun battement de cœur à entretenir.

LibreHU-service exposes two states: FLAG_ACC (the ignition line, at once) and FLAG_POWERED (follows ACC but drops only after the engine-start delay, 0..10 s). Screen, sound, amplifier and standby follow POWERED. CAN box (Hiworld)Boîtier CAN (Hiworld)

The CAN box sits on CAN-H / CAN-L and translates the car's bus into its own messages, configured per car (Renault: protocol LNP002). The MCU only relays bytes (USART1, command 10); LibreHU rebuilds and decodes them.Le boîtier CAN est branché sur CAN-H / CAN-L et traduit le bus de la voiture en ses propres messages, réglés par voiture (Renault : protocole LNP002). La MCU ne fait que relayer les octets (USART1, commande 10) ; LibreHU les reconstitue et les décode.

5A A5 LEN CMD D0 .. Dn-1 CS     LEN = n     CS = ((LEN + CMD + D0 + .. + Dn-1) & 0xFF) - 1
ACK: 5A A5 01 FF <cmd> CS

Root handshakeDemande de root

To get every root prompt at once, the launcher sends org.librehu.action.REQUEST_ROOT to each LibreHU package in turn (protected by ROOT_REQUEST); its RootRequestReceiver runs su -c id once and answers org.librehu.action.ROOT_RESULT (package, granted) to reply_to.   • Transport: TCP 47800 (Wi-Fi) or RFCOMM UUID 6c1b2e6a-8f0e-4b8c-9a51-1ebd2d4c0b01; at most 4 connections; a connection that has not finished key exchange and pairing in 80 s is closed.Transport : TCP 47800 (Wi-Fi) ou RFCOMM UUID 6c1b2e6a-8f0e-4b8c-9a51-1ebd2d4c0b01 ; 4 connexions au plus ; une connexion qui n'a pas fini l'échange de clés et l'association en 80 s est fermée.
  • Handshake: ephemeral ECDH P-256 both ways; the head unit signs the SHA-256 of the exchange with its permanent ECDSA P-256 key; the phone checks it against the fingerprint from the QR code.Poignée de main : ECDH P-256 éphémère des deux côtés ; l'autoradio signe le SHA-256 de l'échange avec sa clé ECDSA P-256 permanente ; le téléphone la vérifie avec l'empreinte du QR code.
  • Session: HKDF-SHA256 (RFC 5869) keys, one per direction; AES-256-GCM frames, nonce = direction + counter (replayed, changed or reordered frames are refused).Session : clés HKDF-SHA256 (RFC 5869), une par sens ; trames AES-256-GCM, nonce = sens + compteur (trame rejouée, modifiée ou déplacée refusée).

Or Bluetooth-paired phone + confirmation on the head unit (60 s).Authentification du téléphone : la première fois, le jeton du QR code (24 octets aléatoires, 5 min, usage unique) prouvé par HMAC-SHA256 de l'échange ; l'autoradio donne alors un identifiant et une clé d'accès de 32 octets, prouvée de la même façon à chaque connexion (gardée dans le Keystore Android / trousseau iOS). OBD / ddt4all

  • ELM327 init: ATZ ATE0 ATL0 ATS0 ATH0 ATAT1 ATSP0, then 0100 0120 0140 for supported PIDs; fast values every loop, slow ones every 5 loops; ATRV for the battery voltage. One session at a time (a stale session stops itself).Init ELM327 : ATZ ATE0 ATL0 ATS0 ATH0 ATAT1 ATSP0, puis 0100 0120 0140 pour les PID gérés ; valeurs rapides à chaque tour, lentes tous les 5 tours ; ATRV pour la tension de la batterie. Une seule session à la fois (une session périmée s'arrête d'elle-même).
  • Manufacturer values: ddt4all ECU JSON files (yours, nothing embedded). Addressing like ddt4all: ATSH <send>, ATFCSH, ATFCSD300000, ATFCSM1, ATCRA <recv>, then back to ATSH7DF. Values: firstbyte from 1 (service byte included), bitoffset from the MSB, scaled = (raw × step + offset) / divideby; checked against ddt4all's Python on the same bytes (ObdCarTest).Valeurs constructeur : fichiers JSON de calculateurs ddt4all (les vôtres, rien d'embarqué). Adressage comme ddt4all : ATSH <envoi>, ATFCSH, ATFCSD300000, ATFCSM1, ATCRA <réception>, puis retour à ATSH7DF. Valeurs : firstbyte depuis 1 (octet de service compris), bitoffset depuis le bit de poids fort, scaled = (brut × step + offset) / divideby ; comparé au Python de ddt4all sur les mêmes octets (ObdCarTest).
  • Read-only by design: only services 21 / 22 without parameters are kept at import; no write, reset, actuator test or diagnostic session is ever sent; adapter commands that write its memory (ATPP, ATSD…) are refused.Lecture seule par construction : seuls les services 21 / 22 sans paramètre sont gardés à l'import ; aucune écriture, aucun reset, aucun test d'actionneur ni ouverture de session de diagnostic n'est jamais envoyé ; les commandes qui écrivent la mémoire de l'adaptateur (ATPP, ATSD…) sont refusées.

LibreHU targets the UJC201 first; once it is mature, it will be adapted to other head units. What is already data-driven:LibreHU vise d'abord l'UJC201 ; une fois mûr, il sera adapté à d'autres autoradios. Ce qui est déjà piloté par des données :

  • MCU protocol: JSON profiles (serial port and speed, framing, checksum, ACK, signals, commands, GPIO wiring, audio chip address).Protocole MCU : profils JSON (port et vitesse, trame, contrôle, acquittement, signaux, commandes, câblage GPIO, adresse de la puce audio).
  • Car: CAN vehicle profiles (JSON) and OBD car files; generic OBD-II works on any car.Voiture : profils CAN (JSON) et fichiers voiture OBD ; l'OBD-II générique marche sur toute voiture.
  • Apps: the main edition runs on any Android 9+ device; LibreHU Helper collects what a port needs.Applis : l'édition main tourne sur tout appareil Android 9+ ; LibreHU Helper rassemble ce qu'il faut pour un portage.
