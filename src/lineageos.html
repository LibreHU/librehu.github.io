vbmeta: why and howvbmeta : pourquoi et comment

Android Verified Boot: the vbmeta partition holds the hashes and keys of boot, dtbo and vendor, and a link to system signed with Jancar's key. The bootloader checks it at every boot. The LineageOS system is not signed by Jancar: with the stock vbmeta as it is, the bootloader refuses to start and the unit stays on the maker's logo.Le démarrage vérifié d'Android : la partition vbmeta contient les empreintes et les clés de boot, dtbo et vendor, et un lien vers system signé avec la clé de Jancar. Le bootloader la vérifie à chaque démarrage. Le system de LineageOS n'est pas signé par Jancar : avec le vbmeta d'origine tel quel, le bootloader refuse de démarrer et l'autoradio reste sur le logo du constructeur.

The fix is your own stock vbmeta with verification turned off: two flags of its header (byte 123), 1 = dm-verity off (--disable-verity), 2 = verification off (--disable-verification). LineageOS needs both (value 3). The stock ROM also starts with this vbmeta. The LibreHU zip never writes vbmeta: it checks the flags and stops without writing anything while verification is on.La solution est votre propre vbmeta d'origine avec la vérification coupée : deux drapeaux de son en-tête (octet 123), 1 = dm-verity coupé (--disable-verity), 2 = vérification coupée (--disable-verification). LineageOS a besoin des deux (valeur 3). Le stock démarre aussi avec ce vbmeta. Le zip LibreHU n'écrit jamais vbmeta : il vérifie les drapeaux et s'arrête sans rien écrire tant que la vérification est active.

With fastboot (usual way)Avec fastboot (méthode habituelle)

adb reboot bootloader
fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img
fastboot reboot

vbmeta.img: the one of your backup. From the boot menu, the Fastboot card also reboots into fastboot.vbmeta.img : celui de votre sauvegarde. Depuis le menu de démarrage, la carte Fastboot redémarre aussi en fastboot.

Without fastboot: SP Flash ToolSans fastboot : SP Flash Tool

If the unit no longer reaches fastboot (stuck on the logo), write a copy of vbmeta with both flags set. Windows PowerShell, in the folder of your backup:Si l'autoradio n'atteint plus fastboot (bloqué sur le logo), écrivez une copie de vbmeta avec les deux drapeaux. PowerShell sous Windows, dans le dossier de votre sauvegarde :

$b = [IO.File]::ReadAllBytes("$PWD\vbmeta.img")
if ([Text.Encoding]::ASCII.GetString($b, 0, 4) -ne "AVB0") { throw "not a vbmeta" }
$b[123] = $b[123] -bor 3
[IO.File]::WriteAllBytes("$PWD\vbmeta-disabled.img", $b)

Then SP Flash Tool: Download tab, your scatter file, mode Download Only, untick everything except vbmeta, point it to vbmeta-disabled.img, click Download and connect the unit switched off.Puis SP Flash Tool : onglet Download, votre fichier scatter, mode Download Only, tout décocher sauf vbmeta, le diriger vers vbmeta-disabled.img, cliquer sur Download et brancher l'autoradio éteint.

Never use Format All + Download or Firmware Upgrade: they erase nvram / nvdata (calibration, MAC addresses, identifiers), which only a backup can bring back. Never format /vendor: LineageOS runs on it (drivers, HALs, firmware). Never flash vbmeta without the two flags while LineageOS is installed: the unit would stay on the logo.Jamais Format All + Download ni Firmware Upgrade : ils effacent nvram / nvdata (calibration, adresses MAC, identifiants), que seule une sauvegarde peut remettre. Ne formatez jamais /vendor : LineageOS tourne dessus (pilotes, HAL, firmwares). Ne flashez jamais vbmeta sans les deux drapeaux tant que LineageOS est installé : l'autoradio resterait sur le logo.
