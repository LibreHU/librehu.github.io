vbmeta: why and howvbmeta : pourquoi et comment

Android Verified Boot: the vbmeta partition holds the hashes and keys of boot, dtbo and vendor, and a link to system signed with Jancar's key. The bootloader checks it at every boot. The LineageOS system is not signed by Jancar: with the stock vbmeta as it is, the bootloader refuses to start and the unit stays on the maker's logo.Le démarrage vérifié d'Android : la partition vbmeta contient les empreintes et les clés de boot, dtbo et vendor, et un lien vers system signé avec la clé de Jancar. Le bootloader la vérifie à chaque démarrage. Le system de LineageOS n'est pas signé par Jancar : avec le vbmeta d'origine tel quel, le bootloader refuse de démarrer et l'autoradio reste sur le logo du constructeur.

The fix is your own stock vbmeta with verification turned off: two flags of its header (byte 123), 1 = dm-verity off (--disable-verity), 2 = verification off (--disable-verification). LineageOS needs both (value 3). The stock ROM also starts with this vbmeta. The LibreHU zip never writes vbmeta: it checks the flags and stops without writing anything while verification is on.La solution est votre propre vbmeta d'origine avec la vérification coupée : deux drapeaux de son en-tête (octet 123), 1 = dm-verity coupé (--disable-verity), 2 = vérification coupée (--disable-verification). LineageOS a besoin des deux (valeur 3). Le stock démarre aussi avec ce vbmeta. Le zip LibreHU n'écrit jamais vbmeta : il vérifie les drapeaux et s'arrête sans rien écrire tant que la vérification est active.

With fastboot (usual way)Avec fastboot (méthode habituelle)

adb reboot bootloader
fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img
fastboot reboot

vbmeta.img: the one of your backup. From the boot menu, the Fastboot card also reboots into fastboot.vbmeta.img : celui de votre sauvegarde. Depuis le menu de démarrage, la carte Fastboot redémarre aussi en fastboot.

Without fastboot: SP Flash ToolSans fastboot : SP Flash Tool

If the unit no longer reaches fastboot (stuck on the logo), write a copy of vbmeta with both flags set. Windows PowerShell, in the folder of your backup:Si l'autoradio n'atteint plus fastboot (bloqué sur le logo), écrivez une copie de vbmeta avec les deux drapeaux. PowerShell sous Windows, dans le dossier de votre sauvegarde :

$b = [IO.File]::ReadAllBytes("$PWD\vbmeta.img")
if ([Text.Encoding]::ASCII.GetString($b, 0, 4) -ne "AVB0") { throw "not a vbmeta" }
$b[123] = $b[123] -bor 3
[IO.File]::WriteAllBytes("$PWD\vbmeta-disabled.img", $b)

Then SP Flash Tool: Download tab, your scatter file, mode Download Only, untick everything except vbmeta, point it to vbmeta-disabled.img, click Download and connect the unit switched off.Puis SP Flash Tool : onglet Download, votre fichier scatter, mode Download Only, tout décocher sauf vbmeta, le diriger vers vbmeta-disabled.img, cliquer sur Download et brancher l'autoradio éteint.

Never use Format All + Download or Firmware Upgrade: they erase nvram / nvdata (calibration, MAC addresses, identifiers), which only a backup can bring back. Never format /vendor: LineageOS runs on it (drivers, HALs, firmware). Never flash vbmeta without the two flags while LineageOS is installed: the unit would stay on the logo.Jamais Format All + Download ni Firmware Upgrade : ils effacent nvram / nvdata (calibration, adresses MAC, identifiants), que seule une sauvegarde peut remettre. Ne formatez jamais /vendor : LineageOS tourne dessus (pilotes, HAL, firmwares). Ne flashez jamais vbmeta sans les deux drapeaux tant que LineageOS est installé : l'autoradio resterait sur le logo.

InstallInstaller

  1. Download the latest zip (above), check its SHA256 and copy it to a USB drive or microSD card, not to the internal storage: Format Data erases it.Téléchargez le dernier zip (plus haut), vérifiez son SHA256 et copiez-le sur une clé USB ou une carte microSD, pas dans la mémoire interne : Format Data l'efface.
  2. Flash vbmeta with both flags (vbmeta), then fastboot reboot.Flashez vbmeta avec les deux drapeaux (vbmeta), puis fastboot reboot.
  3. Boot menu → TWRP (or fastboot oem reboot-recovery).Menu de démarrage → TWRP (ou fastboot oem reboot-recovery).
  4. First install only (coming from the stock or another ROM): Wipe → Format Data, type yes. LineageOS cannot start on the stock /data.Première installation seulement (en venant du stock ou d'une autre ROM) : Wipe → Format Data, tapez yes. LineageOS ne peut pas démarrer sur le /data du stock.
  5. Install → the zip on the USB drive or microSD → swipe. It writes system (read back and checked), boot and the kernel's Wi-Fi / Bluetooth / GPS / FM modules into /vendor/lib/modules (originals backed up in /sdcard/LibreHU/backup). It keeps the boot image type you have (with or without the boot menu); bootmenu or plain in the zip's name forces one.Install → le zip de la clé USB ou de la microSD → glisser. Il écrit system (relu et vérifié), boot et les modules Wi-Fi / Bluetooth / GPS / FM du noyau dans /vendor/lib/modules (originaux sauvegardés dans /sdcard/LibreHU/backup). Il garde le type d'image de boot que vous avez (avec ou sans le menu de démarrage) ; bootmenu ou plain dans le nom du zip en impose un.
  6. Reboot → System. The first boot takes a few minutes. The boot menu (TWRP / Android / Fastboot) starts Android by itself after 3 seconds.Reboot → System. Le premier démarrage prend quelques minutes. Le menu de démarrage (TWRP / Android / Fastboot) lance Android tout seul au bout de 3 secondes.

First bootPremier démarrage

  • Choose LibreHU Launcher as the home screen, Always (Trebuchet stays as a fallback).Choisissez LibreHU Launcher comme écran d'accueil, Toujours (Trebuchet reste en secours).
  • Installed by themselves: the KernelSU Next manager, Aurora Store and LibreHU Helper (normal apps: they update themselves, and stay away once uninstalled).Installés tout seuls : le gestionnaire KernelSU Next, Aurora Store et LibreHU Helper (applis ordinaires : elles se mettent à jour seules, et ne reviennent pas une fois désinstallées).
  • Every LibreHU app gets root from KernelSU without asking (all the org.librehu.* packages and ViPER4Android, at every boot: KernelSU shows no prompt, an app without a profile is refused silently). A choice you make later in the KernelSU manager, refusal included, is kept.Toutes les applis LibreHU reçoivent le root de KernelSU sans le demander (tous les paquets org.librehu.* et ViPER4Android, à chaque démarrage : KernelSU n'affiche pas de demande, une appli sans profil est refusée en silence). Un choix fait ensuite dans le gestionnaire KernelSU, refus compris, est gardé.
  • The touch calibration of your panel is applied at every boot, from /jancar/config/pointercal*.xml.La calibration du tactile de votre dalle est appliquée à chaque démarrage, depuis /jancar/config/pointercal*.xml.
  • The Wi-Fi country comes from the language chosen in the setup (for instance French (France) → FR), from the next boot on; CN (as on the stock) until then.Le pays du Wi-Fi vient de la langue choisie à l'installation (par exemple français (France) → FR), à partir du démarrage suivant ; CN (comme le stock) jusque-là.
  • The panel is a 720 × 1280 portrait panel turned to landscape (90°). Upside down? adb root, adb shell setprop persist.librehu.display_rotation 270, adb reboot.La dalle est une dalle portrait 720 × 1280 tournée en paysage (90°). À l'envers ? adb root, adb shell setprop persist.librehu.display_rotation 270, adb reboot.

Back to stockRetour au stock

TWRP → Restore your backup (Boot, System Image, Vendor Image), then Wipe → Format Data and reboot. The vbmeta with both flags can stay: the stock starts with it. Without TWRP: your SP Flash Tool readback, Download Only, partitions one by one.TWRP → Restore de votre sauvegarde (Boot, System Image, Vendor Image), puis Wipe → Format Data et redémarrage. Le vbmeta aux deux drapeaux peut rester : le stock démarre avec. Sans TWRP : votre lecture SP Flash Tool, Download Only, partition par partition.
