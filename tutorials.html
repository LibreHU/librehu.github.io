Getting startedPremiers pas

1. First install (stock ROM)1. Première installation (ROM d'origine)

  1. On a PC, download LibreHU-OTA-main.apk and copy it to a FAT32 USB stick.Sur un PC, télécharger LibreHU-OTA-main.apk et le copier sur une clé USB en FAT32.
  2. Plug the stick into the head unit, open it in the file manager, tap the APK, allow "install unknown apps" for the file manager.Brancher la clé sur l'autoradio, l'ouvrir dans le gestionnaire de fichiers, toucher l'APK, autoriser « installer des applis inconnues » pour le gestionnaire.
  3. Open LibreHU Apps. Quick setup: choose ivi (Jancar's ivi-services kept) for a first try, allow root if asked, keep the ticked apps, Install.Ouvrir LibreHU Apps. Configuration rapide : choisir ivi (ivi-services de Jancar gardé) pour un premier essai, autoriser le root si demandé, garder les applis cochées, Installer.
  4. Press Home, choose LibreHU Launcher → Always, then follow its assistant.Appuyer sur Accueil, choisir LibreHU Launcher → Toujours, puis suivre son assistant.

2. Switch to LibreHU service2. Passer à LibreHU service

  1. In LibreHU Apps → Settings → Edition, choose LibreHU service; install LibreHU service and update the apps to that edition.Dans LibreHU Apps → Réglages → Édition, choisir LibreHU service ; installer LibreHU service et mettre les applis à jour dans cette édition.
  2. Disable Jancar's service from a PC (USB debugging on): adb shell pm disable-user --user 0 com.jancar.services.Désactiver le service de Jancar depuis un PC (débogage USB actif) : adb shell pm disable-user --user 0 com.jancar.services.
  3. Open LibreHU service: Home must show the link RUNNING and the MCU version. Grant root with "remember".Ouvrir LibreHU service : l'accueil doit montrer la liaison RUNNING et la version de la MCU. Accorder le root avec « se souvenir ».
  4. Go back any time: adb shell pm enable com.jancar.services and the ivi edition.Retour possible à tout moment : adb shell pm enable com.jancar.services et l'édition ivi.

3. Install or update without Internet3. Installer ou mettre à jour sans Internet

  1. On a PC, download the APKs (and zips) from the download table onto a USB stick.Sur un PC, télécharger les APK (et zips) depuis le tableau de téléchargement sur une clé USB.
  2. LibreHU Apps → Settings → USB stick (offline): pick the files. APKs must carry the LibreHU key; images and zips must match a SHA-256 of the last list received online.LibreHU Apps → Réglages → Clé USB (hors ligne) : choisir les fichiers. Les APK doivent porter la clé LibreHU ; images et zips doivent correspondre à un SHA-256 de la dernière liste reçue en ligne.

4. LibreHU apps on another Android device4. Les applis LibreHU sur un autre appareil Android

On any Android 9+ device (tablet, other head unit), install the generic edition (main branch): launcher, dialer, widgets, BtnRemap, EasySource, Disc, OTA. Car data, MCU and audio chip functions stay empty without LibreHU service and the Jancar hardware.Sur tout appareil Android 9 ou plus (tablette, autre autoradio), installer l'édition générique (branche main) : launcher, téléphone, widgets, BtnRemap, EasySource, Disc, OTA. Les fonctions voiture, MCU et puce audio restent vides sans LibreHU service et le matériel Jancar.

SystemSystème

5. Back up the eMMC (SP Flash Tool)5. Sauvegarder l'eMMC (SP Flash Tool)

  1. Install SP Flash Tool and the MediaTek USB VCOM driver on a Windows or Linux PC; load the unit's scatter file (MT6761_Android_scatter.txt).Installer SP Flash Tool et le pilote USB VCOM MediaTek sur un PC Windows ou Linux ; charger le fichier scatter de l'appareil (MT6761_Android_scatter.txt).
  2. Readback tab: add one line per region, with the addresses of the TWRP README (preloader, user area up to cache, end of disk; userdata optional).Onglet Readback : ajouter une ligne par zone, avec les adresses du README de TWRP (preloader, zone utilisateur jusqu'au cache, fin de disque ; userdata en option).
  3. Start Readback, then connect the powered-off unit by USB. Keep the files private: they contain your unit's calibration and identifiers.Lancer Readback, puis brancher l'autoradio éteint en USB. Garder les fichiers privés : ils contiennent la calibration et les identifiants de votre autoradio.

6. Install TWRP6. Installer TWRP

  1. With root: LibreHU Apps → Zips → Recovery → twrp-ujc201 (stable) or -beta (steering wheel and CAN box keys). The current recovery is saved in /sdcard/LibreHU/backup.Avec root : LibreHU Apps → Zips → Recovery → twrp-ujc201 (stable) ou -beta (touches du volant et du boîtier CAN). Le recovery actuel est sauvegardé dans /sdcard/LibreHU/backup.
  2. With a PC: adb reboot bootloader, fastboot flash recovery twrp_ujc201.img (from the releases), fastboot oem reboot-recovery.Avec un PC : adb reboot bootloader, fastboot flash recovery twrp_ujc201.img (depuis les releases), fastboot oem reboot-recovery.
  3. Reach TWRP later from the phone app (Tools → reboot to recovery) or LibreHU service. Always flash the released image, never a raw build output.Revenir dans TWRP plus tard depuis l'appli téléphone (Outils → redémarrer en recovery) ou LibreHU service. Toujours flasher l'image des releases, jamais une sortie de build brute.

7. Install the LibreHU kernel7. Installer le noyau LibreHU

  1. Make the eMMC backup first (tutorial 5).Faire d'abord la sauvegarde de l'eMMC (tuto 5).
  2. LibreHU Apps → Zips → Kernel → kernel-librehu, or kernel-librehu-bootmenu for a TWRP / Android / Fastboot menu at boot. The current boot is saved first; the image is checked (fingerprint, header, AVB footer, size) then read back.LibreHU Apps → Zips → Noyau → kernel-librehu, ou kernel-librehu-bootmenu pour un menu TWRP / Android / Fastboot au démarrage. Le boot actuel est sauvegardé d'abord ; l'image est vérifiée (empreinte, en-tête, pied AVB, taille) puis relue.
  3. Reboot. To go back, restore the saved boot image from TWRP.Redémarrer. Pour revenir en arrière, restaurer l'image boot sauvegardée depuis TWRP.

8. Root with KernelSU Next8. Root avec KernelSU Next

  1. Install the LibreHU kernel (tutorial 7): it contains KernelSU Next.Installer le noyau LibreHU (tuto 7) : il contient KernelSU Next.
  2. Install the KernelSU Next manager from LibreHU Apps (its signing key is checked against the catalogue).Installer le gestionnaire KernelSU Next depuis LibreHU Apps (sa clé de signature est vérifiée avec le catalogue).
  3. In the manager, grant root to the LibreHU apps (Superuser list). Optional: remove the stock SuperSU with the supersu-remove zip.Dans le gestionnaire, accorder le root aux applis LibreHU (liste Superuser). En option : retirer le SuperSU d'origine avec le zip supersu-remove.

9. Root for every LibreHU app at once9. Root pour toutes les applis LibreHU d'un coup

Launcher assistant (or Launcher settings → General → setup) → Allow root for every LibreHU app: each app asks in turn, so all prompts come together. Answer each with "remember". KernelSU grants from its manager: LibreHU checks again after 30 s.Assistant du launcher (ou Paramètres du launcher → Général → assistant) → Autoriser le root pour toutes les applis LibreHU : chaque appli demande à son tour, donc toutes les fenêtres arrivent ensemble. Répondre à chacune avec « se souvenir ». KernelSU accorde depuis son gestionnaire : LibreHU revérifie au bout de 30 s.

10. Make it faster with Tweaks10. Plus rapide avec Tweaks

  1. LibreHU service → System → Tweaks: Compile all now (native code for the LibreHU apps, once per version).LibreHU service → Système → Tweaks : Tout compiler maintenant (code natif pour les applis LibreHU, une fois par version).
  2. Turn on CPU boost on touch for smoother scrolling (a bit more heat).Activer Accélérer le processeur au toucher pour un défilement plus fluide (un peu plus de chaleur).
  3. Optional: per cluster governor and min / max frequency, GPU level. Test, then enable Apply at start-up: a start that does not survive 90 s after applying them skips them the next time.En option : gouverneur et fréquences min / max par groupe de cœurs, palier du GPU. Tester, puis activer Appliquer au démarrage : un démarrage qui ne tient pas 90 s après les avoir appliqués les saute la fois suivante.

11. Standby when the ignition goes off11. Veille à la coupure du contact

  1. LibreHU service → System → Standby card: set the delay (3 s default) so a starter dip does not cut the screen.LibreHU service → Système → carte Veille : régler le délai (3 s par défaut) pour qu'une baisse de tension au démarreur ne coupe pas l'écran.
  2. Pick the mode: screen off (cold start next time), standby (fast wake, 7 h to 14 days, airplane mode and GPS off while sleeping) or shutdown.Choisir le mode : écran éteint (démarrage à froid la fois suivante), veille (réveil rapide, 7 h à 14 jours, mode avion et GPS coupés pendant la veille) ou extinction.
  3. Measure the battery after a night in standby before relying on it (not yet validated on every car).Mesurer la batterie après une nuit en veille avant de s'y fier (pas encore validé sur toutes les voitures).

12. Back up and restore the settings12. Sauvegarder et restaurer les réglages

LibreHU service → System → Backup: settings of every LibreHU app (and ViPER4Android, Open Headunit, CarPlay) go to a .tar in Download/LibreHU. Copy it to a USB stick before a reflash; restore from the same screen.LibreHU service → Système → Sauvegarde : les réglages de toutes les applis LibreHU (et ViPER4Android, Open Headunit, CarPlay) vont dans un .tar de Download/LibreHU. Le copier sur une clé USB avant un reflash ; restaurer depuis le même écran.

PhoneTéléphone

13. Pair the phone app13. Associer l'appli téléphone

  1. Install LibreHU Bridge on the phone.Installer LibreHU Bridge sur le téléphone.
  2. Put phone and head unit on the same Wi-Fi (the phone's hotspot works).Mettre le téléphone et l'autoradio sur le même Wi-Fi (le point d'accès du téléphone convient).
  3. On the head unit: launcher assistant, or LibreHU service → Bluetooth → Phone → LibreHU phone app → Pair a phone: a QR code shows for 5 minutes.Sur l'autoradio : assistant du launcher, ou LibreHU service → Bluetooth → Téléphone → Appli téléphone LibreHU → Associer un téléphone : un QR code s'affiche 5 minutes.
  4. On the phone: Pair a head unit → QR code, scan. Or, phone already paired in Bluetooth: Bluetooth, pick the unit, accept on its screen.Sur le téléphone : Associer un autoradio → QR code, scanner. Ou, téléphone déjà appairé en Bluetooth : Bluetooth, choisir l'autoradio, accepter sur son écran.

14. Install the iPhone app14. Installer l'appli iPhone

  1. Download the unsigned LibreHU-iOS-main.ipa (check its SHA-256 in release-ios.txt).Télécharger le LibreHU-iOS-main.ipa non signé (vérifier son SHA-256 dans release-ios.txt).
  2. Install it with AltStore or Sideloadly from a PC or Mac, signed with your Apple ID.L'installer avec AltStore ou Sideloadly depuis un PC ou un Mac, signé avec votre identifiant Apple.
  3. iPhone: Settings → Privacy & Security → Developer Mode on; Settings → General → VPN & Device Management → trust the profile.iPhone : Réglages → Confidentialité et sécurité → Mode développeur activé ; Réglages → Général → VPN et gestion de l'appareil → faire confiance au profil.
  4. Allow camera and local network access, then pair by QR code (Wi-Fi only). With a free Apple ID, re-sign every 7 days (AltStore does it with AltServer on the same Wi-Fi).Autoriser la caméra et le réseau local, puis associer par QR code (Wi-Fi seulement). Avec un identifiant Apple gratuit, re-signer tous les 7 jours (AltStore le fait avec AltServer sur le même Wi-Fi).

15. Show the phone app in Android Auto15. Afficher l'appli téléphone dans Android Auto

Android Auto lists Car App Library apps only when installed by a trusted store. With root on the phone: the app's Reinstall as Google Play button. Without root, from a PC, after uninstalling it: adb install -r -i com.android.vending LibreHU-Bridge-main.apk. Then Android Auto → Customise launcher → tick LibreHU. Pair again afterwards.Android Auto ne liste une appli Car App Library que si elle vient d'un store de confiance. Avec root sur le téléphone : bouton Réinstaller comme Google Play de l'appli. Sans root, depuis un PC, après l'avoir désinstallée : adb install -r -i com.android.vending LibreHU-Bridge-main.apk. Puis Android Auto → Personnaliser le lanceur → cocher LibreHU. Refaire l'association ensuite.

16. Bluetooth calls and music16. Appels et musique en Bluetooth

  1. LibreHU service → Bluetooth: on, visible, car name; pair the phone from the phone's Bluetooth settings.LibreHU service → Bluetooth : activé, visible, nom de la voiture ; appairer le téléphone depuis les réglages Bluetooth du téléphone.
  2. Allow contacts and call log on the phone when asked (PBAP), then use LibreHU Dialer for calls; music plays through A2DP with track info.Autoriser contacts et journal d'appels sur le téléphone quand il le demande (PBAP), puis utiliser LibreHU Dialer pour les appels ; la musique passe en A2DP avec les infos du morceau.
  3. Turn on reconnection and, if wanted, auto answer. Microphone gain and echo cancellation are in Audio.Activer la reconnexion et, si voulu, la réponse automatique. Gain du micro et annulation d'écho sont dans Audio.

CarVoiture

17. Set up the rear view camera17. Régler la caméra de recul

  1. LibreHU service → Vehicle → Reverse: on, mode LibreHU view; allow the camera and "display over other apps".LibreHU service → Véhicule → Recul : activé, mode Vue LibreHU ; autoriser la caméra et « afficher par-dessus les autres applis ».
  2. Set the camera format of your camera (CVBS PAL / NTSC, AHD 720p / 1080p) and the camera (automatic, or by role).Régler le format de votre caméra (CVBS PAL / NTSC, AHD 720p / 1080p) et la caméra (automatique, ou par rôle).
  3. Open the preview (quarter screen): adjust mirror, flip, rotation, zoom, offsets, then the guide lines until they match the car.Ouvrir l'aperçu (quart d'écran) : régler miroir, retournement, rotation, zoom, décalages, puis les lignes de guidage jusqu'à ce qu'elles collent à la voiture.
  4. Choose the engage sound, music lowered or paused, parking radar (CAN box), motion detection. Test with reverse gear.Choisir le son d'engagement, musique baissée ou en pause, radar de recul (boîtier CAN), détection de mouvement. Tester en marche arrière.

18. Add extra cameras18. Ajouter des caméras

Reverse → extra cameras: up to three more (side, second rear, USB UVC camera), each mirrorable. Layout: one at a time (touch switches), side by side or picture in picture. The unit's camera service must accept several cameras at once, otherwise the extra one shows its error.Recul → caméras en plus : jusqu'à trois de plus (latérale, deuxième arrière, caméra USB UVC), chacune en miroir si besoin. Disposition : une à la fois (un toucher change), côte à côte ou incrustée. Le service caméra de l'autoradio doit accepter plusieurs caméras à la fois, sinon la caméra en plus affiche son erreur.

19. Connect an OBD adapter19. Brancher un adaptateur OBD

  1. Plug an ELM327 into the OBD socket (under the steering wheel on a Clio 3).Brancher un ELM327 sur la prise OBD (sous le volant sur une Clio 3).
  2. Bluetooth adapter: pair it in Android first. USB adapter: plug it and allow USB access.Adaptateur Bluetooth : l'appairer d'abord dans Android. Adaptateur USB : le brancher et autoriser l'accès USB.
  3. LibreHU service → Vehicle → OBD: on, choose the adapter; state goes to connected. Choose the values to read and those of the widget.LibreHU service → Véhicule → OBD : activé, choisir l'adaptateur ; l'état passe à connecté. Choisir les valeurs à lire et celles du widget.
  4. Add the OBD, OBD gauges or digital OBD cluster widget in a launcher slot; read and clear fault codes from the same page.Ajouter le widget OBD, Compteurs OBD ou Combiné OBD numérique dans un emplacement du launcher ; lire et effacer les codes défaut depuis la même page.

20. Car battery monitoring20. Surveiller la batterie

With the OBD adapter connected, the battery card shows the estimated charge engine off and the charging state engine running. Set the alarm thresholds (low battery, no charge, overvoltage), the sound, and a voltage correction if your adapter reads 0.1–0.3 V off. Cars with a smart alternator may sit near 12.5 V while running: lower the threshold or turn that alarm off.Avec l'adaptateur OBD connecté, la carte batterie montre la charge estimée moteur arrêté et l'état de charge moteur tournant. Régler les seuils d'alarme (batterie faible, pas de charge, surtension), le son, et une correction de tension si l'adaptateur lit 0,1 à 0,3 V à côté. Les voitures à alternateur piloté peuvent rester vers 12,5 V moteur tournant : baisser le seuil ou couper cette alarme.

21. Read manufacturer values (ddt4all)21. Lire les valeurs constructeur (ddt4all)

  1. Get ddt4all's ecu.zip (its json/ folder: one file per ECU) yourself; LibreHU embeds none.Récupérer vous-même l'ecu.zip de ddt4all (son dossier json/ : un fichier par calculateur) ; LibreHU n'en embarque aucun.
  2. OBD page → car → import the ECU files of your car (or a librehu-obd-car file), choose the values to show.Page OBD → voiture → importer les fichiers des calculateurs de votre voiture (ou un fichier librehu-obd-car), choisir les valeurs à afficher.
  3. Only read requests are kept: nothing can write to the car. CAN ECUs only; values needing an extended session stay "—".Seules les requêtes de lecture sont gardées : rien ne peut écrire dans la voiture. Calculateurs CAN seulement ; les valeurs qui demandent une session étendue restent à « — ».

22. Map the steering wheel buttons22. Régler les boutons du volant

  1. Open LibreHU BtnRemap, press each wheel button once: it appears in the list (wired keys and CAN box keys alike).Ouvrir LibreHU BtnRemap, appuyer une fois sur chaque bouton du volant : il apparaît dans la liste (touches câblées comme touches du boîtier CAN).
  2. For each button choose the short press and long press action (app, next source, play / pause, track, volume, voice assistant…).Pour chaque bouton, choisir l'action d'appui court et d'appui long (appli, source suivante, lecture / pause, piste, volume, assistant vocal…).
  3. Key test mode shows each press and what it would do, without running it; two buttons pressed together can become a combination.Le mode test des touches montre chaque appui et ce qu'il ferait, sans l'exécuter ; deux boutons appuyés ensemble peuvent devenir une combinaison.
  4. Clio 3: the wheel sends a SRC press at ignition; the "ignore keys at start" delay (5 s) hides it.Clio 3 : la commande au volant envoie un appui SRC à la mise du contact ; le délai « touches ignorées au démarrage » (5 s) le masque.

23. Write a CAN profile for a new car23. Écrire un profil CAN pour une nouvelle voiture

  1. Configure the CAN box for your car (its own protocol), then LibreHU service → Vehicle → CAN → profile hiworld-generic.Régler le boîtier CAN pour votre voiture (son propre protocole), puis LibreHU service → Véhicule → CAN → profil hiworld-generic.
  2. Start a capture and use one control at a time (doors, lights, wheel buttons, reverse): changed bytes are highlighted. Export the text.Lancer une capture et actionner une commande à la fois (portes, feux, boutons du volant, marche arrière) : les octets modifiés sont en couleur. Exporter le texte.
  3. Write the profile (format), import it, check the decoded values live. Share it in an issue or on Discord.Écrire le profil (format), l'importer, vérifier les valeurs décodées en direct. Le partager dans une issue ou sur Discord.

24. Tyre pressure sensors (TPMS)24. Capteurs de pression des pneus (TPMS)

  1. Plug the USB TPMS receiver (the kind sold with "USB TPMS" apps) into the head unit and allow USB access for LibreHU Launcher.Brancher le récepteur TPMS USB (le genre vendu avec les applis « USB TPMS ») sur l'autoradio et autoriser l'accès USB pour LibreHU Launcher.
  2. Open Tyres from the app drawer: pair each wheel (deflate the tyre slightly or follow the sensor's pairing method), swap positions if needed.Ouvrir Pneus depuis le tiroir d'applis : appairer chaque roue (dégonfler légèrement le pneu ou suivre la méthode d'appairage du capteur), permuter les positions si besoin.
  3. Set the pressure and temperature thresholds; add the Tyres widget.Régler les seuils de pression et de température ; ajouter le widget Pneus.

25. Calibrate the touch screen25. Calibrer l'écran tactile

  1. LibreHU service → Display → Touch panel → calibrate (root). If the corners cannot be reached, tick start from a neutral matrix.LibreHU service → Écran → Dalle tactile → calibrer (root). Si les coins sont inaccessibles, cocher partir d'une matrice neutre.
  2. Touch the 5 targets precisely; the maximum error shows.Toucher précisément les 5 cibles ; l'erreur maximale s'affiche.
  3. During the 20 s trial, touch around: Keep saves it; doing nothing goes back to the previous calibration.Pendant l'essai de 20 s, toucher un peu partout : Garder l'enregistre ; ne rien faire revient à la calibration précédente.

26. Learn the front panel touch keys26. Apprendre les touches tactiles de façade

Touch panel page → front keys → add: hold the printed button for 2 s, then give it a short press action and either a long press action or "repeat while held" (good for volume). Actions include home, back, recent apps, volume, play / pause, screen off, open an app or any Android key code.Page Dalle tactile → touches de façade → ajouter : tenir le bouton sérigraphié 2 s, puis lui donner une action d'appui court et soit une action d'appui long, soit « répéter tant qu'on appuie » (bien pour le volume). Actions possibles : accueil, retour, applis récentes, volume, lecture / pause, écran éteint, ouvrir une appli ou n'importe quel code de touche Android.

Media and projectionMédias et projection

27. FM radio27. Radio FM

  1. Open LibreHU FM, turn the radio on, scan the band: stations are listed.Ouvrir LibreHU FM, allumer la radio, balayer la bande : les stations sont listées.
  2. Settings: RDS (station name, radiotext, traffic info), station logos (server, country), audio path.Paramètres : RDS (nom de station, radiotexte, info trafic), logos des stations (serveur, pays), chemin audio.
  3. Add the FM widget on the dashboard (one gesture from the launcher's second slot).Ajouter le widget FM sur le tableau de bord (en un geste depuis le second emplacement du launcher).

28. Use the MODE / SRC key28. Utiliser la touche MODE / SRC

Open LibreHU EasySource: turn sources on and order them (FM, Bluetooth music, AUX, music apps), set the delay. Then in BtnRemap, give the MODE button "EasySource: next source". Each press shows the next source full screen; it starts after the delay or at once with OK.Ouvrir LibreHU EasySource : activer et ordonner les sources (FM, musique Bluetooth, AUX, applis de musique), régler le délai. Puis dans BtnRemap, donner au bouton MODE « EasySource : source suivante ». Chaque appui montre la source suivante en plein écran ; elle démarre après le délai ou tout de suite avec OK.

  4. First time with a phone: plug it in over USB and leave the cable in for a minute.   5. Wireless: the unit has a single Wi-Fi radio, so the Wi-Fi Direct group follows the network the unit is joined to. If that network is on a 5 GHz channel outside DFS (36-48, 149-161), the group goes on the same channel and the radio does not switch back and forth; on 2.4 GHz, DFS or with no network, the group takes a free 5 GHz channel (wireless Android Auto needs 5 GHz) and the radio time-shares while the unit stays connected. 40. When Android hangs40. Quand Android est bloqué

Reset SoC (phone app, or LibreHU service → System → Watchdog card) asks the MCU to power cycle the SoC: it works even when Android no longer responds. Safe shutdown mutes, pauses, writes data to disk and tells you when you can turn the ignition off.Redémarrer le SoC (appli téléphone, ou LibreHU service → Système → carte Watchdog) demande à la MCU de couper et rallumer le SoC : ça marche même quand Android ne répond plus. Arrêt sécurisé coupe le son, met en pause, écrit les données et indique quand couper le contact.
