Car engineMoteur voiture

What LibreHU knows of your car (keys, doors, speed, engine, climate, parking sensors) comes from one engine that knows no car: everything is in car profiles, small files read by the engine, like the code lists of a universal remote.Ce que LibreHU sait de votre voiture (touches, portes, vitesse, moteur, clim, radar) vient d'un seul moteur qui ne connaît aucune voiture : tout est dans des fiches de voiture, de petits fichiers lus par le moteur, comme les listes de codes d'une télécommande universelle.

In shortEn bref

  • Adding or fixing a car = changing its profile, not the app.Ajouter ou corriger une voiture = changer sa fiche, pas l'appli.
  • A CAN box and an OBD-II adapter can be plugged in at the same time: their values are merged.Un boîtier CAN et une sonde OBD-II peuvent être branchés en même temps : leurs valeurs sont réunies.
  • Industry standards instead of home-made ones: COVESA VSS for the names, SAE J1979 for OBD-II, Semantic Versioning, JSON Schema.Des standards de l'industrie plutôt que des inventions maison : COVESA VSS pour les noms, SAE J1979 pour l'OBD-II, Semantic Versioning, JSON Schema.

Car profilesFiches de voiture

A profile is a JSON file: which box, how to answer it, where each value is in its messages. Format 2 adds what the decoders of Hiworld's app need:Une fiche est un fichier JSON : quel boîtier, comment lui répondre, où est chaque valeur dans ses messages. Le format 2 ajoute ce dont les décodeurs de l'appli de Hiworld ont besoin :

  • common names for every value, multiplexed messages, conditions, invalid values, labels in each language;noms communs pour chaque valeur, messages multiplexés, conditions, valeurs invalides, libellés par langue ;
  • formulas (D4 == 0 ? -D5 : D4), a profile extending another, per-car patches;formules (D4 == 0 ? -D5 : D4), une fiche qui en complète une autre, retouches par voiture ;
  • the box's framing, messages built from the head unit's state (the clock…), commands, several key sources and knobs;la trame du boîtier, des messages construits depuis l'état de l'autoradio (l'horloge…), des commandes, plusieurs sources de touches et molettes ;
  • self-tests in each profile, checked on every build.des auto-tests dans chaque fiche, vérifiés à chaque compilation.

Full format: docs/can-vehicles.md; JSON Schema for editors: can-vehicle.schema.json. Cars decoded today: list.Format complet : docs/can-vehicles.md ; schéma JSON pour les éditeurs : can-vehicle.schema.json. Voitures décodées aujourd'hui : liste.

VersionsVersions

The engine follows Semantic Versioning: a profile says the engine it needs ("engine": ">=2.1"); an older service refuses it with a clear message instead of reading it half, and every earlier format stays readable.Le moteur suit le Semantic Versioning : une fiche dit le moteur qu'elle demande ("engine": ">=2.1") ; un service plus ancien la refuse avec un message clair au lieu de la lire à moitié, et tous les anciens formats restent lisibles.

Updates by makeMises à jour par marque

Profiles are published by make in LibreHU-car-profiles and offered by LibreHU Apps (Zips page → Cars): fixing a Renault updates the Renault pack only, not the service nor the other makes. A pack needs a given engine version; LibreHU Apps only offers those your service can read, checks the download (SHA-256, also listed in dist/SHA256SUMS) and the service reads it again all or nothing, keeping the SHA-256 of what it installed (service v172, LibreHU Apps with the Cars tab). The built-in profiles stay as a fallback.Les fiches sont publiées par marque dans LibreHU-car-profiles et proposées par LibreHU Apps (page Zips → Voitures) : corriger une Renault met à jour le paquet Renault seulement, ni le service ni les autres marques. Un paquet demande une version du moteur ; LibreHU Apps ne propose que ceux que votre service sait lire, vérifie le téléchargement (SHA-256, listé aussi dans dist/SHA256SUMS) et le service le relit tout ou rien, en gardant le SHA-256 de ce qu'il a installé (service v172, LibreHU Apps avec l'onglet Voitures). Les fiches intégrées restent en secours.

Port a carPorter une voiture

  1. Capture: CAN tab, raw profile of your box, export while using each control (keys, doors, lights…).Capturer : onglet CAN, fiche brute de votre boîtier, export en actionnant chaque commande (touches, portes, feux…).
  2. Find the bytes that change (shown in orange) and what they mean.Repérer les octets qui changent (en orange) et ce qu'ils veulent dire.
  3. Write the profile from the template, with a common name for each value.Écrire la fiche à partir du modèle, avec un nom commun pour chaque valeur.
  4. Test: add self-tests (a message and the values it must give), import the profile in the CAN tab.Tester : ajouter des auto-tests (un message et les valeurs qu'il doit donner), importer la fiche dans l'onglet CAN.
  5. Share it: pull request or "New car" issue on LibreHU-car-profiles (template template/new-car.json, guide PORTING.md, tool librehu-car-tool.jar to check it without the car).La partager : pull request ou ticket « Nouvelle voiture » sur LibreHU-car-profiles (modèle template/new-car.json, guide PORTING.md, outil librehu-car-tool.jar pour la vérifier sans la voiture).

Drafts from the stock Car Info app (work in progress)Brouillons tirés de l'appli Car Info d'origine (en cours)

A tool of the profiles repository, tools/carinfo/, reads the jadx "fallback" listing of the stock Car Info app (the app is never run) and replays its code in a small interpreter: which decoder for which car, which messages, which bytes, which formula. On 6 November 2026 it finds a decoder for 6,658 of the 6,970 catalogue entries (532 decoders), with the same results as the hand analyses for PSA (111 / 111) and Volkswagen (174 / 174). Not done yet: writing the profiles (box family or framing, roles, keys, car type, acknowledgements) and checking them with librehu-car-tool.jar check. Profiles drawn from it will be marked not tested until someone tries them on the car.Un outil du dépôt des fiches, tools/carinfo/, lit le listage jadx « fallback » de l'appli Car Info d'origine (l'appli n'est jamais exécutée) et rejoue son code dans un petit interpréteur : quel décodeur pour quelle voiture, quels messages, quels octets, quelle formule. Au 6 novembre 2026, il trouve un décodeur pour 6 658 des 6 970 entrées du catalogue (532 décodeurs), avec les mêmes résultats que les analyses à la main pour PSA (111 / 111) et Volkswagen (174 / 174). Pas encore fait : l'écriture des fiches (famille de boîtier ou framing, rôles, touches, type de voiture, accusés) et leur vérification par librehu-car-tool.jar check. Les fiches qui en sortiront seront marquées non testées tant que personne ne les a essayées sur la voiture.

RobustnessRobustesse

  • Formulas are computed, never run as code, and limited in length.Les formules sont calculées, jamais exécutées comme du code, et limitées en longueur.
  • A profile is checked when it is read (unknown name, bad formula, too new engine: refused with the reason).Une fiche est vérifiée à la lecture (nom inconnu, formule fausse, moteur trop récent : refusée avec la raison).
  • Messages to the box are spaced (500 ms at least for repeated ones); a knob gives 10 steps at most per message.Les messages au boîtier sont espacés (500 ms au moins pour ceux qui se répètent) ; une molette donne 10 crans au plus par message.
  • One source stopping leaves the others' values.Une source qui s'arrête laisse les valeurs des autres.
